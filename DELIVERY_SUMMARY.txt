🚀 HOW TO GET STARTED (5 SIMPLE STEPS)
================================================================================

Step 1: Create GitHub Account (2 min)
   → Go to https://github.com/signup
   → Complete signup
   → Verify email

Step 2: Create Repository (1 min)
   → Click "+" → "New repository"
   → Name it "portfolio"
   → Select "Public"
   → Create

Step 3: Upload Files (5 min)
   → Click "Add file" → "Upload files"
   → Drag and drop all files
   → Click "Commit changes"

Step 4: Enable GitHub Pages (2 min)
   → Go to Settings
   → Click "Pages"
   → Select "Deploy from a branch"
   → Select "main" branch, "/ (root)" folder
   → Save

Step 5: View Your Website (1 min)
   → GitHub shows your live URL
   → Visit your website
   → You're live! 🎉
